# Changelog

Each release's section also appears on its GitHub release page.

## 0.2

- Windows remember their size and place on each display, per app: a window
  sent or dragged to a display gets back where its app's windows last were
  there.
- Hold the click with the keys to snap to the grid. Moving and resizing are
  otherwise free, with edge snapping.
- Every display has a grid, sized for it the first time it's seen: no more
  grid switch or default size.
- The settings have a sidebar, with a page per topic and one per display.
- New Portrait (2 × 3) grid preset, and the fine ultrawide one is now 8 × 4.

## 0.1

- First version: move or resize the window under the pointer by holding
  modifier keys, with edge snapping, a grid per display, and sending windows
  to another display with a swipe, the wheel or arrow keys.
- A portable executable (x64 and Arm), and an installer for the current user
  or all users.
